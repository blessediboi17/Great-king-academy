Data Protection & Privacy Policy

1. Information Collection: Great King Academy collects student names, access codes, class assignments, and grade evaluations solely for educational management.

2. Data Security: All grade transmissions utilize HTTPS TLS encryption. Database access is strictly governed by Row Level Security (RLS) policies in Supabase.

3. Access Restrictions: Students may only view their own registered report card. Grade edits require explicit admin approval.
